# Собери монстра

Мобильная браузерная игра: за 30 секунд лови разноцветные фигуры, глаза, рты, ладошки и ботинки. В конце из пойманных тобой деталей собирается странное существо — ничего не добавляется «из воздуха».

Это прогрессивное веб-приложение (PWA): можно играть прямо в браузере или поставить иконку на экран «Домой», как обычное приложение.

## Играть

**[Открыть игру](https://sergeyduvakin.github.io/sobery-monstra/)**

## Как добавить на экран «Домой» (iPhone)

1. Открой ссылку выше в **Safari** (не в Chrome и не из встроенного браузера мессенджера).
2. Нажми кнопку «Поделиться» — квадрат со стрелкой вверх внизу экрана.
3. Прокрути список действий и выбери **«На экран Домой»**.
4. Если нужно, поправь название и нажми «Добавить».

После этого игра откроется как отдельное приложение, без адресной строки Safari. На Android похожий пункт обычно называется «Установить приложение» или «Добавить на главный экран» в меню браузера.

## Локальный запуск

```bash
cd sobery-monstra
python3 -m http.server 8080
# открыть http://localhost:8080
```

Через `file://` лучше не открывать: сервис-воркер и манифест так не заработают.

## Что внутри

- `index.html` — вся игра на HTML5 Canvas и JavaScript, без сборки и без зависимостей
- `manifest.json` — манифест PWA (standalone, портретная ориентация)
- `sw.js` — офлайн-кэш оболочки приложения
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `favicon.png` — иконки для домашнего экрана и вкладки
